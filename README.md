# Price Compare Agent（比价 Agent）

一个站在买方一边的比价 agent：输入一个商品，跨商家比**到手总价**，并把每一分钱的构成摊开给你看。

## 灵感来源

Stripe CEO Patrick Collison 2026-10-09 在 X 上的长文《Assorted things I've been mulling over
regarding agents in the economy》：公司是“原始的超级智能”，能用摊薄的认知盈余对付
注意力有限、信息不足的消费者；个人 agent 会缩小这个差距——帮人搜替代品、比条款、
找折扣、盯着订阅——从而成为“产品质量的结构性补贴”。
本项目就是把这篇里的“比价”一环动手做出来：**agent 只为买方服务**。

## 买方立场（不可妥协的原则）

1. **只为买方排序**：排名只看对买方有利的因素（到手总价、到货时间、商家信誉），
   绝不接受付费排名、广告位、佣金倾斜。将来如果有联盟佣金收入，必须在结果里明示，
   且不得影响排序。
2. **先算总账**：比的不是标价，是到手总价 = 商品价 + 运费 + 预估税费 − 可用优惠，
   并列出每一项和来源、抓取时间。
3. **同款才比**：只有 UPC / EAN / MPN / 官方 SKU 一致的才算“同款”；标题像但标识
   对不上的，单独标注“疑似同款、未确认”，不混进排名。
4. **不替你乱花钱**：自动下单（如果未来做）必须同时满足：你事先点头 + 单笔上限 +
   商家白名单 + 总预算帽，缺一不可。默认只比价、不下单。
5. **合规拿数据**：优先官方 API / 商品 Feed / 联盟目录；遵守 robots.txt 与商家 ToS，
   被屏蔽就停下来换合法渠道，不绕验证、不伪造身份。

## 快速开始（最小骨架，模拟商家数据）

```bash
cd price-compare-agent
python3 -m price_agent.cli compare "Sony WH-1000XM5"
python3 -m unittest discover -s tests -v
```

输出示例：各商家到手总价排名、每项构成、到货天数、商家评分。
当前版本是骨架：商家是模拟数据，用于验证比价核心与排名逻辑；
真实商家接入按 `PLAN.md` 的阶段推进。

## 路线图（摘要，详见 PLAN.md）

- Phase 0：立项与开源基建（本仓库）——已启动
- Phase 1：同款比价核心（标识归一 + 到手总价 + 透明账单）
- Phase 2：质量信号（评价、退货、商家信誉）与价格追踪提醒
- Phase 3：受约束的代下单（白名单 + 上限 + 事先点头）
- Phase 4：品类扩展与公开评测集（拿真实商品定期回归排名质量）
